This is a repo containing some of the basic code and drivers for some of my small and quick stm32 projects. I have them split by the two boards that I have. The NUCLEO-N657X0-Q dev board I specifically chose for the camera connector for the VL53L9CX time of flight sensor. I am thinking of designing a PCB with this sensor, the ISM330 IMU, and an STM32 to see if I can do on-board edge SLAM. I think that it would be cool. For now, I am testing out these sensors with breakout boards and breadboards.
